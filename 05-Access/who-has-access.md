## The Golden Rule
> The business owner MUST always hold master admin access to ALL systems.
> Never allow a developer, designer, or vendor to be the sole account owner.
> If they leave your project, you must still be able to access everything.

### Access Levels Explained
- Full Admin: Can do everything including delete the website. Owner only.
- Developer: Can edit code and settings. Should not have billing access.
- Editor: Can add and edit content only. No design or code access.
- Viewer: Can see but not change anything.

## Security Rules Checklist

- [ ] All accounts use strong passwords (12+ characters, mix of letters, numbers, symbols)
- [ ] Two-factor authentication (2FA) enabled on all critical accounts
- [ ] Owner has all recovery codes stored safely offline
- [ ] No passwords shared via WhatsApp or regular email
- [ ] Access removed immediately for anyone who leaves the project
- [ ] Password manager used to store credentials (e.g. 1Password, Bitwarden)
- [ ] Owner has tested logging into every account personally
