## Scope Change Process
> If a new feature or change is requested AFTER development has started:

1. Write down the new request clearly
2. Ask the developer for a cost and time estimate
3. Decide if it should be added now or planned for later
4. Get written confirmation before proceeding
5. Update the features list and timeline documents
